Descrição do Dataset

Tabela 74 — IBGE Pecuária Municipal

O dataset é extraído da Pesquisa da Pecuária Municipal (PPM) do IBGE, cobrindo todos os municípios do estado do Amazonas com registro de produção de leite bovino.

Estrutura original do CSV

O arquivo contém 3 sub-tabelas concatenadas: produção física (Mil litros), valor da produção (Mil reais) e percentual estadual. Cada linha representa um município; as colunas representam anos.

Variável utilizada

Produção de leite (Mil litros/ano) — série histórica de 2004 a 2024 para os 62 municípios do AM.

Fundamento Teórico

Principal Component Analysis — PCA

O PCA é uma técnica de redução de dimensionalidade linear que transforma variáveis correlacionadas em componentes ortogonais que maximizam a variância capturada.

X_centrado = X - μ
C = (1/n) · Xᵀ · X   ← Covariância
C · v = λ · v         ← Autovetor
PC_k = X · v_k

Propriedades Chave

  • Componentes são ortogonais entre si
  • Variância decrescente do PC1 ao PCn
  • Requer padronização Z-score prévia
  • Interpretação via loadings (pesos)

O que o PCA revela

Cada ponto projetado em 2D representa um município. A distância entre pontos reflete a diferença de perfil produtivo. Os vetores de loading indicam quais anos mais influenciam cada componente.

Scree Plot

Gráfico da variância explicada por componente, utilizado para decidir quantas PCs são necessárias para representar adequadamente os dados sem perda significativa de informação.

Limitação

O PCA é linear — relações não-lineares entre variáveis podem não ser bem capturadas na projeção 2D.

Fundamento Teórico

Multidimensional Scaling — MDS

O MDS projeta as observações em baixa dimensão preservando ao máximo as distâncias (ou dissimilaridades) entre pares de pontos no espaço original.

D_ij = ||x_i - x_j|| ← distâncias
D_norm = D / max(D) ← normalização
minimizar: Stress = √(Σ(d̂_ij - d_ij)²/Σd²)

MDS Métrico vs. Não-Métrico

  • Métrico: preserva os valores das distâncias
  • Não-Métrico: preserva apenas a ordem (rank) das distâncias — mais robusto para dados reais

Interpretação do Stress

  • Stress < 0.05 → Excelente
  • Stress < 0.10 → Boa
  • Stress < 0.20 → Aceitável
  • Stress ≥ 0.20 → Ruim

Diferença do PCA

O PCA otimiza a variância; o MDS otimiza as distâncias entre pares. MDS é melhor para detectar agrupamentos baseados em similaridade global.

Estratégia adotada

Utilizamos MDS Não-Métrico com matriz de dissimilaridade Euclidiana pré-computada e normalizada para melhor estabilidade numérica.

Pré-processamento

Seleção, Limpeza e Padronização

Features selecionadas

Cada um dos 21 anos (2004–2024) como dimensão independente do perfil municipal.

Justificativa: Cada ano é uma variável numérica contínua (Mil litros). Tratando municípios como observações e anos como features, o PCA/MDS identifica municípios com trajetórias temporais similares.

Pipeline de limpeza

  • Remoção de municípios com >50% de NaN (4 excluídos)
  • Imputação pela mediana anual nos restantes
  • Padronização Z-score (μ=0, σ=1)
58
Municípios finais

Features (anos)

Por que padronizar?

Municípios como Autazes produzem ~9.700 Mil litros/ano, enquanto outros produzem <10 Mil litros. Sem padronização, os valores absolutos dominariam as componentes, perdendo a informação estrutural das trajetórias.

z = (x − μ) / σ  →  μ=0.000 σ=1.000

Interpretação do Scree Plot

A PC1 sozinha captura 91,3% da variância total. Apenas 1 componente já supera a marca de 80%, o que indica que o perfil produtivo dos municípios é dominado por um único fator: o nível absoluto de produção.

Loadings do PC1

Todos os anos têm loading positivo e próximo entre si — PC1 representa o volume geral de produção do município. Não há ano dominante, o que indica uma estrutura de produção historicamente consistente.

Resultados PCA

Projeção 2D e Agrupamentos

Três grupos bem definidos

A projeção 2D captura 95,7% da variância total (PC1+PC2) e revela três clusters bem separados:

  • ● Alta produção — Autazes, Careiro, Parintins, Apuí, Itacoatiara
  • ● Média produção — grupo intermediário
  • ● Baixa produção — maioria dos municípios

Outliers visíveis

Autazes e Careiro da Várzea estão completamente isolados do grupo de alta produção, confirmando seu status de maiores bacias leiteiras do Amazonas.

PC2 — Tendência temporal

Municípios que oscilaram muito ao longo dos anos aparecem deslocados verticalmente, enquanto produtores estáveis ficam horizontalmente agrupados.

Resultados PCA

Biplot — Municípios e Vetores dos Anos

Leitura do Biplot

Cada vetor/seta representa um ano. Quanto mais longo e alinhado com o eixo PC1, mais o ano contribui para diferenciar municípios por volume de produção. Vetores paralelos indicam anos com padrões de produção similares.

Observação central

Todos os vetores apontam na mesma direção (PC1 positivo), confirmando que todos os anos medem essencialmente a mesma coisa: o potencial produtivo absoluto do município.

Implicação prática

O histórico de produção de leite é um atributo estruturalmente estável no AM. Municípios que sempre foram grandes produtores mantiveram essa posição.

Qualidade da representação

O stress 0,0075 indica que a projeção 2D preserva de forma quase perfeita as distâncias originais entre os 58 municípios no espaço de 21 dimensões. Os padrões visuais são confiáveis.

Agrupamentos confirmados

Vantagem do MDS aqui

O MDS captura melhor diferenças relativas entre municípios do grupo médio, enquanto o PCA os comprime na escala da PC1.

Conclusões

Síntese e Aprendizados

Padrão dominante descoberto

A produção leiteira no AM é altamente concentrada. Autazes e Careiro da Várzea juntos correspondem a uma fração desproporcional da produção estadual, com padrões estáveis ao longo de 20 anos.

PCA — Adequação excelente

95,7% de variância explicada em 2 dimensões. A estrutura de dados é inerentemente unidimensional (apenas o volume diferencia os municípios), o que facilita a interpretação.

MDS — Validação independente

Stress de 0,0075 — qualidade excelente. Os agrupamentos do PCA foram totalmente confirmados pelo MDS, elevando a confiança nos resultados.

Potencial para modelos de ML

Apenas 1 PC captura 91,3% da informação — a redução seria de 21 features para 1 sem perda significativa. O MDS é melhor reservado para visualização do que para feature reduction em pipelines preditivos.
